# Bundled fonts

Inter (`ui/fonts/inter-latin.woff2`) and Barlow Condensed Bold
(`ui/fonts/barlow-condensed-700-latin.woff2`) are shared with the owner's
MotionModule design. They are bundled for offline use on robot Wi-Fi networks.

The SIL Open Font License notices are distributed with the app:

- [Inter license](../ui/fonts/OFL-Inter.txt)
- [Barlow Condensed license](../ui/fonts/OFL-BarlowCondensed.txt)

The controller drawing is original SVG arranged to match the standard control
layout on Hardware Tester. The app does not embed that website or its scripts.
