Use gamepad input
Steam Deck trackpads & back paddles
Launch this app from Steam and select Gamepad with Mouse Trackpad. Edit this app’s layout:
  • Right trackpad: As Mouse; click: Left Mouse Click.
  • Left trackpad: Scroll Wheel; click: Right Mouse Click.
  • Both sticks: Joystick. Triggers, bumpers, D-pad and face buttons: their normal Gamepad outputs.
  • Enable back grips. Bind L4/R4/L5/R5 to the robot’s gamepad buttons, for example A/B/X/Y. Distinct extra buttons appear in Inputs only if the driver exposes them.
Steam owns these bindings and requires this layout setup once. Desktop mouse mode can turn triggers into clicks; launch through Steam for this app’s separate layout. Trackpads navigate both the dashboard and robot page.
The robot defines what each control does. Robot gamepad outputs stay neutral while this test is open.
